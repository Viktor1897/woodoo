# SIMPLE Barbershop

React and TypeScript starter with the Next.js App Router and CSS Modules.

Use Node.js 24 and npm. Run `npm ci` to install dependencies and `npm run dev`
to start the development server. Run `npm run lint`, `npm run typecheck`, and
`npm run build` to verify the site. The production build writes static files to
`out/`.

The homepage lives in `src/app/page.tsx`. Site metadata lives in
`src/app/layout.tsx`. The original favicon set, manifest, and social preview
image keep their public URLs. Additional original photos can be recovered from
`assets/images/` at Git revision `c9e621a`.
